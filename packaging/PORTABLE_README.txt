LOF iNAV Windows 便携版使用说明
================================

适用版本：LOF_iNAV-Portable-*-win-x64.zip

LOF iNAV 是一个免费、开源，在您自己电脑上运行并通过浏览器查看的本地工具。它
不需要安装 Python，不需要使用命令行，也不会把网页开放给局域网或互联网。程序
运行期间会访问公开的基金、行情、指数和汇率数据源，因此要获得最新数据仍需连接
互联网。

估值是怎样计算的
----------------

本项目不是直接把最新公布净值当成“实时净值”。它先根据基金已经披露的持仓，或者
根据基金跟踪的指数、ETF、商品、债券等建立人工代理规则，构造一组可跟踪的底层
资产及其权重。页面中“持仓/代理资产”展示的就是当前用于估值的这组资产。

估值过程可以简化理解为：

1. 以基金最后一次公布的单位净值及其净值日期为起点。
2. 计算每项已建模底层资产从该净值日期到最新可用行情的累计涨跌。
3. 外币资产同时计算对应人民币汇率的累计变化，把资产涨跌折算成人民币收益。
4. 按各项资产权重加总，得到基金从最后净值日以来的估算涨跌。
5. 用“最后公布净值 ×（1 + 估算涨跌）”得到估算 iNAV，再用场内交易价格与估算
   iNAV 计算折溢价率。

不同资产的实时行情口径有所不同：

- A 股、港股和美股使用其正常交易时段内的最新盘中行情；休市后使用最近收盘数据。
- 股票类资产目前不使用美股盘前、盘后或其他股票夜盘数据。
- 美元、港币等外币资产会叠加相对人民币的汇率变化；汇率缺失时会产生数据警报，
  相关仓位可能无法正常计价。
- 黄金、原油等连续交易品种会使用其全天交易时段的实时行情，包括股票市场
  收盘后的行情；实际新鲜度仍取决于第三方数据源。

这种方法存在天然限制：基金持仓公告有披露滞后，公开持仓可能不完整，人工代理不等
于真实持仓，未建模或缺少行情的仓位不能准确贡献收益，基金经理调仓、现金、费用、
衍生品和杠杆路径也可能造成偏差。回测只能帮助观察历史误差，不能证明当前估值正确，
更不能保证未来有效。使用估算结果前，请查看具体基金的“持仓/代理资产”、覆盖比例、
数据警报和最近回测，而不要只看估算 iNAV 或折溢价率。


一、使用前准备
------------

1. 一台 Windows 10 或 Windows 11 的 64 位电脑。
2. Edge、Chrome 或其他现代浏览器。
3. 可正常访问互联网的网络环境。
4. 建议预留至少 500 MB 可用空间，供程序、数据库和日志使用。

本版本无需安装，不需要管理员权限，也不需要另外安装 Python。

建议把程序放在本机一个固定、可写的目录，例如：

    D:\LOF_iNAV\

不要放在“Program Files”等受系统保护的目录；也不建议长期放在临时目录、网盘同步
目录或 U 盘中运行。运行时不要移动、重命名或删除程序目录中的文件。


二、解压与首次启动
----------------

1. 找到下载的 LOF_iNAV-Portable-版本号-win-x64.zip。
2. 右键 ZIP，选择“全部解压”，解压到一个新的文件夹。
3. 打开解压后的同名文件夹。应能看到：

    LOF_iNAV.exe          启动程序
    关闭 LOF_iNAV.bat    关闭程序
    使用说明.txt          本说明
    _internal\            程序运行文件，请勿修改或删除
    config\               基金估值规则，请勿随意修改
    LICENSE               开源许可证

4. 双击 LOF_iNAV.exe。第一次启动可能比平时稍慢，请只启动一次并耐心等待。
5. 程序会自动打开浏览器，通常显示类似下面的本地地址：

    http://127.0.0.1:8001

6. 页面出现基金列表后即可使用。首次启动会在程序目录中新增 data 文件夹，并把
   随包数据初始化为本机数据库：

    data\lof_inav.sqlite3

随包数据库让页面无需长时间初始化即可显示数据。打开页面后，程序还会在后台检查
和更新净值、行情、申购状态、公告与持仓；刚启动时出现“刷新中”、进度百分比，或
部分按钮暂时变灰，通常都是正常现象。

如果 Windows 显示“Windows 已保护你的电脑”，请先确认文件来自可信发布渠道且
文件校验值正确。确认无误后，可选择“更多信息”→“仍要运行”。不要为了运行本程序
而关闭 Windows Defender 或其他安全软件。


三、日常启动和使用
----------------

每次使用按下面操作即可：

1. 打开已经完整解压的 LOF iNAV 文件夹。
2. 双击 LOF_iNAV.exe，只启动一次。
3. 等待浏览器自动打开；页面加载后可以正常浏览。
4. 使用结束后，按本说明第五节的方法关闭程序。

页面常用功能：

- 类型筛选：按研究用途划分的类别选择基金，具体说明见下文。
- 申购限额：可以隐藏暂停申购的基金。
- 折溢价率：按自己填写的阈值筛选溢价或折价基金，默认 1.5%。
- 表头排序：点击支持排序的列名切换排序方向。
- 编辑表头：选择主表中显示哪些列。
- 查看详情：点击任意基金行，查看持仓/代理资产和最近回测。
- 导出 CSV / 导出 PNG：把当前页面的筛选结果导出，具体说明见下文。
- 刷新：重新读取当前列表和状态；到了后台更新周期时，程序会自动发起相应更新。
- 增量回测：补充最近净值对应的短期回测。普通日常查看不需要反复点击。

页面会在使用期间自动刷新。长时间停留在后台标签页时刷新频率会降低；重新切回页面
后会再次更新。

基金分类与筛选说明
~~~~~~~~~~~~~~~~

页面中的类型是为了方便研究和筛选而设置的简化分类，包括：

- A 股-指数、A 股-主动：主要观察 A 股指数或主动管理组合。
- QDII-港股、QDII-美股、QDII-多市场：主要按境外市场暴露划分。
- 商品-贵金属、商品-原油、商品-混合：主要按商品投资主题划分。
- 债券-境内债、债券-美元债：主要按债券市场和币种暴露划分。
- FOF：主要通过其他基金形成投资敞口。

实际显示哪些类型取决于当前版本收录的基金。页面默认不勾选 A 股类别，主要突出跨
市场基金；需要查看 A 股时可以手动勾选，也可以用“全选”和“全不选”快速切换。

这些分类不是监管部门的正式产品分类，也不代表基金只持有分类名称所写的资产。尤其
需要注意：

- “商品-贵金属”是贵金属主题，底层可能是黄金、白银等商品行情，也可能是黄金 ETF、
  矿业公司股票、相关基金或人工等效代理。
- “商品-原油”是原油或能源主题，底层可能是 WTI、Brent 等原油敞口，也可能是原油
  ETF/ETC、油气公司股票、能源基金或人工等效代理。
- “商品-混合”和“QDII-多市场”可能同时含有多种商品、股票、债券和基金。

因此，不能只根据分类名称判断基金的真实风险或当日涨跌来源。点击基金行后，应查看
“持仓/代理资产”中的具体标的、权重、行情时间和来源，并结合基金正式公告判断。

导出功能说明
~~~~~~~~~~~~

“导出 CSV”和“导出 PNG”都会以点击按钮时的页面为准，只导出：

- 当前已经勾选的基金类型；
- 当前申购限额和折溢价阈值筛选后仍可见的基金；
- 当前排序后的行顺序；
- “编辑表头”中当前选择显示的列。

被筛掉的基金、隐藏的列，以及页面下方的持仓/代理资产和逐条回测详情不会进入导出
文件。需要某些字段时，请先在“编辑表头”中把对应列勾选出来再导出。

- 导出 CSV：生成 UTF-8 编码的表格文件，可用 Excel 或其他表格软件继续筛选、排序
  和分析。文件第一行是当前可见列的列名。
- 导出 PNG：生成便于查看或分享的长图片，包含当前筛选摘要、顶部刷新状态、可见
  列表和免责声明。

文件通常由浏览器保存到“下载”目录，实际位置以浏览器设置为准。导出文件只是当时的
静态快照，不会继续自动更新。分享或二次加工导出结果时，请保留时间和数据口径，并
明确说明它是非官方估算；CSV 本身不附带完整免责声明，不能脱离本说明当作投资结论。


四、怎样看顶部状态
----------------

- “净值”：最近一次成功更新基金净值的时间。
- “行情”：最近一次成功更新证券行情的时间。
- “回测”：最近一次增量回测任务的完成时间。
- “数据”：现有回测数据的最新日期或日期范围。
- 百分比进度条：后台正在抓取或计算，请等待完成。

“数据 无数据”只表示没有可展示的回测记录，不等于净值、行情或基金列表全部没有
数据。“增量回测”按钮变灰，通常表示回测已经在运行，或者净值、持仓更新正在占用
相关数据；等当前任务结束后按钮会自动恢复。

点击“刷新”并不代表强制重新下载所有数据。程序会根据不同数据的更新间隔决定哪些
内容需要联网更新，以减少无效请求和被数据源限流的风险。


五、正确关闭程序
----------------

仅仅关闭浏览器标签页或浏览器窗口，不会关闭 LOF iNAV；程序仍会在后台运行。

正确关闭方法：

1. 如果页面仍显示后台任务进度，建议先等待进度结束。
2. 可以先关闭浏览器中的 LOF iNAV 页面。
3. 回到程序文件夹，双击“关闭 LOF_iNAV.bat”。
4. 黑色窗口显示“LOF iNAV server stopped”或提示未发现正在运行的程序后，按任意键
   关闭窗口。

如果之前误点了多次 LOF_iNAV.exe，可能启动了不止一个进程。此时可以再次双击
“关闭 LOF_iNAV.bat”，直到本地页面无法再打开。也可以在 Windows 任务管理器中结束
残留的 LOF_iNAV.exe，但应优先使用随包关闭脚本。

关闭程序后，数据库仍保存在 data 文件夹中，下次启动会继续使用，不需要重新初始化。


六、版本升级
------------

便携版各版本相互独立，推荐按下面方式升级：

1. 使用“关闭 LOF_iNAV.bat”彻底退出旧版。
2. 下载新版 ZIP。
3. 把新版 ZIP 解压到一个新的文件夹，不要覆盖旧版文件夹。
4. 双击新版文件夹中的 LOF_iNAV.exe。
5. 确认新版可以打开且基金列表正常后，可以直接删除整个旧版文件夹。

不需要把旧版 data 文件夹复制到新版。新版自带与其规则匹配的数据，启动后会继续
联网更新。不要同时运行新旧两个版本，它们可能争用相同的本地端口。

如果希望保留旧版本作为备份，可以先保留旧文件夹，但再次使用旧版前要确保新版已经
关闭。


七、备份、移动和卸载
------------------

- 备份：先关闭程序，再复制整个 LOF iNAV 文件夹。
- 移动：先关闭程序，再把整个文件夹移动到新的本机目录，不要只移动 EXE。
- 卸载：先关闭程序，再删除整个 LOF iNAV 文件夹即可。

导出的 CSV 和 PNG 通常位于浏览器下载目录，不会随程序文件夹一起删除。


八、常见问题
------------

1. 双击 EXE 后没有自动打开浏览器

   先等待一分钟，不要连续双击。然后在浏览器中尝试打开：

       http://127.0.0.1:8001

   如果仍无法访问，双击“关闭 LOF_iNAV.bat”后重新启动一次。程序在 8001 端口被
   占用时会自动改用后续端口，并正常情况下自动打开正确页面。

2. 浏览器提示“无法访问此网站”或“拒绝连接”

   通常表示程序尚未启动、已经退出，或被安全软件拦截。确认 LOF_iNAV.exe 和
   _internal 文件夹仍在同一目录，完整重新解压后再试。不要直接在 ZIP 压缩包内运行。

3. 页面能打开，但数据较旧、部分数据缺失或提示刷新失败

   先确认网络正常，等待几分钟后点击“刷新”。公开数据源可能临时超时、限流或休市，
   程序会继续显示已有缓存；可以稍后重新启动再试。已有数据不代表此刻的官方数据。

4. “增量回测”按钮是灰色的

   后台可能正在更新净值、持仓或回测。等待顶部进度结束即可，无需反复点击或重启。

5. 页面显示“数据 无数据”

   这只表示回测记录暂时缺失。基金列表、净值和行情仍可能正常。等待后台任务完成，
   必要时再点击一次“增量回测”。

6. 程序目录里出现了 data 文件夹

   这是正常的。data 中保存本机数据库、运行日志和进程信息。程序运行时不要编辑、
   移动或删除其中的文件，也不要把数据库上传到公共渠道。

7. 程序疑似重复启动、数据库忙或关闭一次后页面仍能打开

   连续执行“关闭 LOF_iNAV.bat”，直到页面无法访问，然后只双击一次 LOF_iNAV.exe。

8. 怀疑本地数据损坏，程序始终无法启动

   先关闭程序，把 data 文件夹重命名为 data_backup，再启动 LOF_iNAV.exe。程序会从
   随包数据库重新初始化新的 data 文件夹。确认恢复正常前不要删除 data_backup；如仍
   有问题，可将 data\lof_inav.log 提供给维护者排查，但分享前请自行检查内容。

9. 杀毒软件删除或隔离了文件

   不要直接关闭安全软件。先确认下载来源和发布者提供的文件校验值，再查看隔离记录；
   无法确认文件可信时不要运行。确认下载文件损坏时，应从可信渠道重新下载并解压。


九、隐私和网络说明
----------------

LOF iNAV 页面只监听本机回环地址 127.0.0.1，不供局域网或互联网中的其他电脑访问。
程序会访问公开的基金、行情、指数和汇率数据源来更新数据。本地数据库和日志保存在
程序目录的 data 文件夹中。请勿把程序目录放在自动公开共享的位置。
