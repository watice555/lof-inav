LOF iNAV Windows Portable
=========================

使用方法
1. 完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 LOF_iNAV.exe。
3. 程序会在本目录的 data 文件夹中创建和更新本地缓存，并自动打开浏览器。

升级方法
1. 退出旧版本。
2. 把新版 ZIP 解压到一个新的文件夹。
3. 运行新版 LOF_iNAV.exe；确认正常后可直接删除旧版本文件夹。

每个版本都是独立的。无需复制旧版 data 文件夹，也不要把新版覆盖解压到旧版目录。
本工具展示的是估算结果，不是基金公司公布的官方净值，也不构成投资建议。
