安装 Python 指南

本指南以 Windows 电脑为例，适合第一次安装 Python 的用户。安装完成后，可以在命令行中使用 python 命令运行 Python 程序。

1. 打开 Python 官网

打开 Python 官网：

https://www.python.org/

进入官网后，点击顶部菜单里的 Downloads，再进入 All releases，选择需要安装的 Python 版本。

2. 选择推荐版本

建议安装：

Python 3.12.10

很多 Python 程序会要求一个最低 Python 版本，而过新的 Python 版本有时会遇到第三方依赖还没有完全适配的问题。3.12 是比较稳妥的选择，3.12.10 是 3.12 系列中提供安装包的较新版本。

也可以直接打开这个下载页面：

https://www.python.org/downloads/release/python-31210/

3. 下载安装包

进入下载页面后，向下找到 Files 区域。

对于绝大多数 Windows 用户，选择：

Windows installer (64-bit)

点击后浏览器会下载一个 Python 安装包，文件名通常类似：

python-3.12.10-amd64.exe

4. 安装 Python

双击下载好的安装包。

在第一个安装界面，务必勾选：

Add python.exe to PATH

然后点击：

Install Now

后续如果出现设置选项，保持默认或全选即可。等待安装完成。

5. 验证安装是否成功

安装完成后，按 Windows 键，输入：

cmd

打开命令提示符后，输入：

python -V

然后按回车。

如果看到类似下面的输出，说明安装成功：

Python 3.12.10

常见问题

如果输入 python -V 后提示找不到 Python，通常是安装时没有勾选 Add python.exe to PATH。可以重新运行安装包，选择修改安装，或卸载后重新安装一次。

如果电脑上已经安装过其他 Python 版本，一般也可以继续使用。只要 python -V 能正常显示版本号，就说明当前命令行可以找到 Python。
