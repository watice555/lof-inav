项目快速运行指南

本指南适合想快速把网页跑起来的用户。运行前请先确认电脑已经安装 Python，并且安装时勾选了 Add python.exe to PATH。如果还没有安装，可以先看同目录下的 安装python指南.md。

1. 下载项目 ZIP

打开本项目公开地址：

https://github.com/watice555/lof-inav

在页面右上方找到绿色的 Code 按钮，点击后选择 Download ZIP。

浏览器会下载一个类似 lof-inav-main.zip 的压缩包。

2. 放到安全的目录下

建议先在电脑上新建一个专门放项目的目录，例如：

D:\Projects

然后把下载好的 lof-inav-main.zip 移动到这个目录里。

不建议放在以下位置：

C:\Windows、C:\Program Files 等系统目录
桌面、下载文件夹这类容易误删的位置
路径很深、权限复杂、会自动同步的目录

3. 解压 ZIP

右键 lof-inav-main.zip，选择 全部解压缩 或使用 7-Zip、WinRAR 等工具解压。

解压后会得到一个项目文件夹，通常叫：

lof-inav-main

进入这个文件夹后，应当能看到 quick_start.bat、README.md、requirements.txt 等文件。

4. 运行快速启动脚本

双击：

一键快速构建并启动.bat

脚本会自动完成以下工作：

1. 创建本项目自己的 Python 虚拟环境 .venv
2. 安装项目依赖
3. 第一次运行时执行快速构建
4. 启动本地网站
5. 自动打开浏览器

这里的快速构建只拉取实时估值需要的必要数据，不会刷新历史日线，也不会运行回测。相比完整构建，它能大幅降低第一次启动前的等待时间。

不过快速构建仍然需要访问行情、净值、公告、汇率等数据源，第一次运行还是需要等一会儿。等待期间不要直接关闭命令窗口，看到浏览器打开或终端继续输出服务地址后再操作网页。

启动成功后，浏览器会打开：

http://127.0.0.1:8000

如果浏览器没有自动打开，也可以手动复制上面的地址到浏览器地址栏。

5. 下次如何运行

以后继续使用时，仍然可以双击：

一键快速构建并启动.bat

如果本地数据已经存在，脚本会跳过第一次构建，直接启动网站。

也可以双击：

启动本地服务.bat

如果想重新抓取当前估值数据，可以在项目目录空白处按住 Shift 并右键，选择 在终端中打开，然后运行：

.\quick_start.bat --rebuild

6. 如何停止服务运行

想要停止服务运行时，双击：

停止本地网站.bat

单纯地关闭浏览器窗口并不会停止本地服务，服务仍在后台运行，重新在浏览器打开 http://127.0.0.1:8000 可继续访问。

常见问题

如果提示找不到 Python，通常是 Python 没有安装，或者安装时没有勾选 Add python.exe to PATH。

如果窗口里出现下载或连接失败，可能是网络访问数据源不稳定。可以等一会儿重新双击 quick_start.bat。

如果 Windows 弹出安全提醒，确认文件来自自己下载的项目地址后，选择允许运行即可。
